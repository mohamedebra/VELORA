# نشر VELORA مجاناً

إعداد النشر الحالي مناسب للتجربة على MonsterASP.NET، ويتطلب إنشاء الحساب والخدمات من لوحة التحكم.

## 1. إنشاء الموقع وقاعدة البيانات

1. أنشئ حساباً مجانياً في [MonsterASP.NET](https://www.monsterasp.net/) ثم أنشئ موقعاً جديداً.
2. أنشئ قاعدة بيانات MSSQL من لوحة التحكم، وانسخ **connection string المحلية الخاصة بالتطبيق**.
3. أضف إعدادات الموقع التالية في إعدادات البيئة على الخادم:
   - `ConnectionStrings__Velora`: connection string التي نسختها من لوحة قاعدة البيانات.
   - `VeloraAdmin__Email`: بريد دخول لوحة تحكم VELORA.
   - `VeloraAdmin__Password`: كلمة مرور قوية للوحة التحكم.

لا تضف هذه القيم إلى GitHub أو ملفات المشروع. عند تشغيل الـ API، ينشئ جداول المنتجات والطلبات والإعدادات تلقائياً. إذا كانت قاعدة المنتجات فارغة، يحمل المشروع كتالوج البداية من `Data/products.seed.json`.

## 2. إعداد النشر التلقائي من GitHub

1. من لوحة MonsterASP.NET، فعّل WebDeploy للموقع وسجّل قيم Server وSite وLogin وPassword.
2. في مستودع GitHub افتح **Settings → Secrets and variables → Actions → New repository secret**، وأضف:
   - `WEBSITE_NAME`
   - `SERVER_COMPUTER_NAME`
   - `SERVER_USERNAME`
   - `SERVER_PASSWORD`
3. اطلب تفعيل HTTPS للموقع المجاني من دعم الاستضافة بعد أول نشر.
4. ادفع أي تحديث إلى فرع `main`. سير العمل في `.github/workflows/deploy.yml` يبني React و.NET API معاً ثم ينشرهما على الموقع.

الواجهة والـ API يعملان من نفس عنوان الموقع، وقاعدة SQL تبقى على استضافة MSSQL. لا تُرفع ملفات قاعدة البيانات أو كلمات المرور إلى Git.

## حدود الخطة المجانية

الخطة المجانية مخصصة للتجربة والمشاريع الصغيرة: الموارد مشتركة، الذاكرة 256 MB، حد قاعدة البيانات 1 GB، النسخ الاحتياطي التلقائي اليومي غير متاح، وAlwaysRunning غير متاح. انسخ قاعدة البيانات يدوياً بانتظام، واستخدم الخطة للتجربة قبل الاعتماد عليها في طلبات عملاء حقيقية.
